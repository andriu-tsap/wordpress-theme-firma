# Serwis Nurt · WordPress Block Theme

Projekt koncepcyjny – marka fikcyjna

Motyw blokowy dla fikcyjnej firmy zajmującej się przeglądami i konserwacją instalacji.

## Overview

A Polish service-business site concept for WordPress FSE commissions. It includes a homepage, About, Services, Contact, and two reusable block patterns.

## Files

- `serwis-nurt/`: WordPress block theme, global styles, template parts and patterns.
- `releases/serwis-nurt.zip`: installable theme package for WordPress.
- `index.html`, `o-nas.html`, `uslugi.html`, `kontakt.html`: static demo with matching styling.

## Installation and editing

Use WordPress 6.6 or newer. In Appearance → Themes → Add New → Upload Theme, upload the ZIP and activate it. Create pages for About, Services and Contact, assign the corresponding templates in the page editor, and add the pages to Navigation in Appearance → Editor. Use the Site Editor to change the palette, templates and patterns. Update business details before deploying to a real site.

## Technology

WordPress block markup, theme.json version 3, PHP pattern metadata, HTML and CSS. The contact address is illustrative.
